### Contract requests (v3)

- POST /api/speak has error codes beyond docs/API.md: 504 `TTS_TIMEOUT` (20 s deadline), 502 `TTS_FAILED` (upstream error). Clients should treat ANY non-200 as "fall back to the device voice". 503 carries `details.reason` (NO_KEY / TERMS_REQUIRED / UNAVAILABLE); 429 TTS_RATE_LIMITED carries `details.retryAfter` (seconds) and `retryAfterMs`; unknown-voice 400 carries `details.voices`.
- Consider documenting the account-wide Groq cap (100 Orpheus requests/day, 1,200 chars/min) in docs/API.md, so clients batch two short sentences per request where they can instead of one request per short sentence.
