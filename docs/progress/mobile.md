- `api.voice.speak()` takes no AbortSignal, so stop() can only ignore in-flight requests (they still count against the 100/day). An optional `signal` in the shared client would let us cancel them.

- Optional: a server-side trim of leading silence on /api/speak would make the client-side WAV trim unnecessary (web would benefit too).
